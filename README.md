# Hopper — H100, FP8, and the Transformer Engine

A deep dive into NVIDIA's Hopper architecture: the GH100 die (H100, H100 NVL, H200), 4th-generation tensor cores with native FP8, the Transformer Engine for automatic FP8 scaling, the Tensor Memory Accelerator (TMA), thread-block clusters and distributed shared memory, DPX, NVLink 4, and the GH200 Grace-Hopper superchip. Includes an interactive Hopper variant picker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_07_Hopper/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
